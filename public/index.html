Two tickers, one truth.

TWINTICKER is an AI agent on Binance Agent OS that watches Ondo-tokenized US stocks on BNB Chain and compares them to the underlying US equity in real time. It flags divergence, explains why it matters, and — with your own wallet — can swap into the mispriced token via the Binance Agentic Wallet.

Live demo — scan a symbol

Pick a US ticker and TWINTICKER will pull the live on-chain price of its Ondo token, the live US equity price, and the official sharesMultiplier, then compute the divergence in basis points and apply a deterministic verdict. The natural-language rationale is written by gpt-4o-mini from the same data. Read-only — no wallet, no keys, no execution.

How it works

Three agents run in sequence, each written to be small, auditable, and replaceable.

1. Reader

Resolves the ticker to an Ondo contract on BNB Chain via the official binance-tokenized-securities-info REST API. Fetches both the live on-chain price (from the same API's dynamic endpoint) and the live US equity price (from its stockInfo field, refreshed every few seconds by Binance's data feed).

2. Analyzer

Applies the Ondo sharesMultiplier to the reference price, computes the divergence in basis points, checks the corporate-action halt code, and emits a deterministic verdict: FAIR_VALUE, UNDERVALUED, OVERVALUED, or HALTED. The LLM is called once to write a one-paragraph rationale from the same numbers — it never invents a verdict.

3. Scanner

Runs the Reader + Analyzer over the full Ondo universe and ranks by absolute divergence, so the most mispriced tokens surface first.

4. Executor (optional)

If the verdict is actionable and you've connected your own Agentic Wallet, TWINTICKER can call baw market-order swap on BSC, capped at $5 per trade. Disabled by default — you wire your own wallet, you confirm every tx in the Binance app.

Safety

  • The hosted site never touches a wallet. The demo is read-only: scan, quote, and an honest dry-run output. No keys, no signing, no broadcast.
  • The verdict is deterministic. The 20-line math that decides FAIR_VALUE / UNDERVALUED / OVERVALUED / HALTED is the same function every time. The LLM is only used to write the rationale from numbers it didn't generate.
  • Execution is the user's job. To actually swap, you install the stdio MCP shim locally, run baw auth signin, and pair your own Agentic Wallet. The hard $5 cap on swap size is enforced on the executor before baw is called.
  • Tokenized equity ≠ equity. A real-world corporate action (dividend, split, earnings halt) can move the on-chain price away from the underlying. TWINTICKER surfaces the official Binance reasonCode in every verdict and refuses to recommend action during a halt.

Connect

Three ways to use TWINTICKER. All three are read-only against the live data; only the local install path can execute (and only against your own wallet).

A. Use the live endpoint in your LLM

claude mcp add twinticker \
  --transport http https://twinticker.vercel.app/mcp

Works with any MCP-compatible LLM (Claude Code, Codex, Cursor, Windsurf, Continue, …). The hosted site is read-only — your LLM can scan and quote through the same endpoint.

B. Install the stdio shim locally

git clone https://github.com/ruzkypazzy/twinticker
cd twinticker && npm install
claude mcp add twinticker -- node $(pwd)/src/mcp-stdio.js

Same tools, over stdio. Works with every MCP client. The shim proxies to the same hosted API — no data is changed.

C. Execute live (your wallet, your call)

# 1. install baw
npm install -g @binance/agentic-wallet
# 2. pair with your wallet
baw auth signin --json
# 3. fund the Agentic sub-account (BSC, USDT)
# 4. wire the local executor
BAW_ENABLED=true npm run mcp

Once paired, twinticker_execute routes through baw market-order swap on BSC. Every tx is confirmed in your Binance app before broadcast. The executor caps each swap at $5 — you raise the cap in the source.

D. Just talk to it from a script

curl -X POST https://twinticker.vercel.app/mcp \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'

The MCP endpoint is just JSON-RPC over HTTP. Pipe it into anything.
