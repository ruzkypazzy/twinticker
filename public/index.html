How it works

TWINTICKER runs three agents: a Reader that pulls on-chain token data via binance-tokenized-securities-info and the underlying US equity price from a free public feed; an Analyzer that computes the divergence in basis points, applies the Ondo multiplier, and produces a verdict (FAIR_VALUE / UNDERVALUED / OVERVALUED / HALTED); and a Scanner that runs the whole pipeline across the full Ondo universe and ranks by absolute divergence. The MCP server exposes both twinticker_scan and twinticker_scan_all to any MCP-compatible agent — Claude Code, Codex, Cursor, ChatGPT. Built for the Binance Agent OS Mini Hackathon.
